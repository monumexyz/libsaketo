# `monero_fastscan`

Simple, experimental, fast and async block scanner for Monero blockchain, aimed to be the fastest Monero scanner of all time, by utilizing asynchrony and multi-threading. Uses some parts of `monero-oxide` crates under the hood.

> [!WARNING]
> This is an experimental project, use at your own risk. Consider privacy and security implications before using it with real wallets. Usage of test wallets is highly recommended.
