# `monero_fastscan_cli`

A simple command line interface of REPL for `monero_fastscan`, a fast and async block scanner for Monero blockchain.

This is used for testing/trying out `monero_fastscan` features quickly from command line.

> [!WARNING]
> This is an experimental project, use at your own risk. Consider privacy and security implications before using it with real wallets. Usage of test wallets is highly recommended.
